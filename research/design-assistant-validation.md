# SCR 设计助理研发与计算验证

更新：2026-11-11。本页是研发计划与验收框架，不代表工具集成或工程计算已验证完成。不比较两种喷射路线。

## 推进顺序与当前状态

按工具集成、计算验证、设计建议优化推进。现有网站采用 VitePress，提供[计算工具入口](/nox-scr-calculator.html)；该入口是否为目标 8 合 1 版本、自动调用能力和计算正确性均待核查。没有测试记录不得标为已完成。

## 本轮任务 1：8 合 1 工具集成准备

**技术目标：** 明确工具版本、8 个模块及输入输出契约。

**实施步骤：** 核对原始 HTML 和线上版本；登记模块、单位、默认值、公式及输出；确定前端函数、页面操作或接口调用方式；保存可复现输入输出。

**测试方法：** 逐一检查全部模块；测试有效输入、必填项缺失、零流量、非正绝压及非法浓度。

**验收标准：** 8 个模块均可定位并有字段映射；正常输入结果可复现；异常输入明确报错；无法调用的模块列为阻塞项。

**潜在风险：** 线上版本与原文件不一致，隐藏默认值，页面逻辑难以独立调用。

## 本轮任务 2：网站资料依据表

**技术目标：** 为工程建议建立可追溯依据。

**实施步骤：** 整理[烟气流量检测](/research/flow-measurement)、[管路及催化剂封装](/research/piping-catalyst-design)、[气助式喷射](/system/air-assist)和[催化剂分析](/system/catalyst)；逐条登记页面、章节、公式、单位、适用条件、来源日期及验证状态；记录冲突与资料缺口。

**测试方法：** 将六项目标输出逐一追溯到依据；检查干湿基、氧折算及不同发动机参数是否被误用。

**验收标准：** 尿素用量、管径、有效长度、流速、停留时间和系统压降均有依据或明确缺口；数值建议有来源及适用边界。

**潜在风险：** 历史研究假设未经验证，其他机器或催化剂数据被直接迁移。已有页面结论不自动等于助理的验证证据。

## 本轮任务 3：六项结果独立复算规范

**技术目标：** 建立网页工具与独立计算的回归验证基线。

**实施步骤：** 统一标况温压、绝压、干湿基、NOx 定义、氧折算和尿素质量分数；建立正常、最低及最高流量、温压变化、长度不足工况；保存原始输入、公式、结果、差值和判定。接口与依据明确后再执行测试。

**测试方法：**

| 输出 | 独立检查 |
| --- | --- |
| 尿素用量 | NOx 摩尔脱除负荷、每摩尔尿素理论产生 2 mol NH3、溶液浓度换算；液体体积另需密度 |
| 混合管内径 | 实际体积流量→面积→圆管内径，并回代流速 |
| 有效长度 | 速度与目标有效停留时间计算，核查可用空间 |
| 流速 | 实际体积流量除以实际截面积 |
| 停留时间 | 有效体积除以实际体积流量；等截面时为有效长度除以速度 |
| 系统压降 | 沿程、局部、混合器和催化剂阻力分项求和 |

**验收标准：** 相同模型、单位及基准下，提出软件数值一致性门槛为相对差不超过 0.1%；零值另约定绝对误差，显示舍入单独记录。该门槛是拟采用的软件检验标准，不是工程预测精度或设备保证。六项均须留存实际测试记录才可判定通过。缺供应商阻力曲线时仅给参数化估算，不冻结系统压降。

**潜在风险：** 两套代码复制同一错误公式；将干标流量直接用于湿工况流速；理论尿素量被误作现场保证量；缺失局部与催化剂阻力。

## 后续设计优化的进入条件

完成工具映射、资料依据表及六项独立复算后，再优化设计建议。按最大实际流量确定管径，复核低负荷流速；区分物理长度、有效喷射至评价面长度、过渡段及检修空间。停留时间不等于充分蒸发、热解和混合的证明。喷枪数量、混合器几何、均匀性及总背压仍需供应商、CFD 或现场验证。
